# DeepSeek V4.1 Flash Integration with Hermes Agent

## Core Instructions

### Obtaining Free API Key
1. **Visit Token Harbor**: Go to `tokenharbor.ai`.
2. **Create Account**: Sign up for a free account.
3. **Generate API Key**: Access settings to create a free API key.

### Integration Steps
1. **Hermes Agent Setup**:
   - Create a separate profile for each API (referred to as "brain").
   - Example profiles: G6 Astra, LFM 2.5 2.6B, GT 5.6.
   - Plug in DeepSeek V4.1 Flash API into Hermes Agent.

2. **Documentation and Training**:
   - Access Token Harbor documentation via the menu bar under "Connect" and "Integration".
   - Use documentation to train AI agents on API usage.

3. **Agent OS Configuration**:
   - Use the command `forward/arn` to teach Hermes Agent a new skill from a guide.
   - Ensure DC Token Harbor is selected before running commands.

### Testing and Verification
- **Performance Check**: Verify API response speed and functionality.
- **Example Outputs**: Test with sample projects like website creation and productivity tools.

## Additional Features
- **Custom Workflows**: Create workflows such as Hermes Oracle, Hermes Apollo, Hermes Muse, and Hermes Asteros.
