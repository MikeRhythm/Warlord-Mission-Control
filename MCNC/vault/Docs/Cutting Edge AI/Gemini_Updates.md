# RESEARCH DOSSIER // Google Gemini In-Chat Document Generation and Editing Capabilities

### 1. CORE NUGGET
Google Gemini has been upgraded to enable direct generation, preview, and editing of various document types (documents, PDFs, presentations, spreadsheets, code, markdown, plain text files) within the Gemini chat interface. This functionality supports iterative refinement by allowing users to highlight specific sections of a generated document and instruct Gemini to modify only that part, eliminating the need to download and edit files in external applications. PDF preview and editing are supported on both web and mobile platforms, while other formats (Google Docs, Google Sheets, Slide decks, Markdown files, TXT files, and code) are web-only for now. This feature is available to all Gemini users in all supported languages and regions without additional cost.

### 3. SUPERSEDES
This update supersedes the previous Gemini functionality where generated files (e.g., CSV, documents) had to be downloaded and then opened in external applications for any preview or editing. The new in-chat generation, preview, and editing capabilities streamline the workflow by keeping all document creation and refinement within the Gemini chat environment, eliminating context switching and manual copy-pasting between different applications.
