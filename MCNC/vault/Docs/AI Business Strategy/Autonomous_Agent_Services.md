# RESEARCH DOSSIER // 7 AI SIDE HUSTLES RANKED (CASH VELOCITY RUBRIC)

### 1. CORE NUGGET
The speaker ranked 7 popular AI side hustles using a five-factor rubric (Startup Cost, Skill Barrier, Weekly Hours Needed, Time to First Credible Sale, Risk) scored from 1 (lowest friction / fastest) to 5 (highest friction / slowest). The total composite score (5 to 25) determines speed to the first paid dollar from a stranger, inverting traditional "income ceiling" hype.

### 2. CODE / IMPLEMENTATION
**Rubric Scoring System (Lower = Faster/Easier):**
* Scale: 1 to 5 per factor (Total: 5–25)
* Evaluated Factors:
  1. Startup Cost
  2. Skill Barrier
  3. Weekly Hours Needed
  4. Time to First Credible Sale
  5. Risk

**Operational Rule of Engagement:**
* **30-to-60 Day Hard Deadline:** Commit to a single model for a minimum 30-day proof-of-concept sprint. Premature abandonment before 30 days is the primary failure vector.

### 3. SUPERSEDES
Income-ceiling-based evaluations that ignore customer trust hurdles, sales friction, and platform payment gates.

# RESEARCH DOSSIER // AI MICROSASS

### 1. CORE NUGGET
AI MicroSaaS (zero-employee software business) is ranked #7 (Score: 22/25). It has the highest upside ceiling but represents the slowest path to the first dollar due to compound skill barriers, product development cycles, and high customer trust resistance.

### 2. CODE / IMPLEMENTATION
**Factor Scores:**
* Startup Cost: 4
* Skill Barrier: 5
* Weekly Hours Needed: 4
* Time to First Credible Sale: 5
* Risk: 4

**Operational Dependencies:**
* Requires end-to-end software development and deployment.
* Requires convincing cold prospects to trust an unproven tool over incumbents.
* High runway to first dollar; not viable as a beginner weekend build. Recommended as a Stage 2 or 3 asset after establishing initial cashflow.

### 3. SUPERSEDES
"Weekend AI SaaS" claims that treat building software as an instant cash-flow generator.

# RESEARCH DOSSIER // AI CONTENT CLIPPING & BOUNTY PLATFORMS (WHOP & VYRO)

### 1. CORE NUGGET
AI Short-Form Content Clipping is ranked #1 (Score: 7/25). It provides the fastest realistic path to the first dollar by eliminating the two biggest hurdles: building an audience and closing sales. Editors clip existing creator assets and submit to pre-funded bounty pools.

### 2. CODE / IMPLEMENTATION
**Factor Scores:**
* Startup Cost: 1
* Skill Barrier: 2
* Weekly Hours Needed: 2
* Time to First Credible Sale: 1
* Risk: 1

**Platform Dependencies:**
* Bounty Rails: Whop and Vyro (creator-funded clipping campaigns).
* Distribution Channels: TikTok, Instagram Reels, YouTube Shorts.
* Monetization Mechanism: Payouts calculated per view generated (CPM) or per accepted clip submission, funded directly by creators/brands.

**Tool Integration:**
* Local AI clippers (e.g., OpusClip, CapCut, or headless FFmpeg/Whisper scripts on Base 1) for vertical 9:16 re-framing and animated subtitle burning.

**Operational Directives:**
1. **Intake:** Identify active campaigns with clear payout structures on Whop or Vyro.
2. **Analysis:** Review 3+ top-performing clips in the target niche to extract pacing, hook structure, and audio styling before editing.
3. **Execution:** Deploy the first batch within 48 hours. Speed of iteration takes precedence over post-production perfection.

### 3. SUPERSEDES
Building audience-dependent social channels from zero when immediate cash velocity is the primary objective.
