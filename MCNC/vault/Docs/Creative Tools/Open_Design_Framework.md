# RESEARCH DOSSIER // Open Design Framework
### 1. Executive Summary & Core Value Proposition
* Open Design is an open-sourced design framework offering unlimited usage without paywalls or subscriptions.
* It supports multiple AI models, including external APIs and local models, allowing for flexible and cost-effective design solutions.
* The framework includes 71 pre-made design systems for professional-looking outputs.

### 2. Technical Architecture & Mechanics
* Open Design allows users to integrate various AI models, such as Chat GPT, Gemini, or custom API keys.
* It features a interactive canvas for iterative design refinement.
* Output formats include HTML, PDF, PowerPoint, and MP4.
* The system is open-sourced and has gained significant traction on GitHub.
