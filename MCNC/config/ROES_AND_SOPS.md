## SECTION 2: UI ROE // THE ZERO-FLAT MANDATE
1. **Zero Naked Solid Fills:**
   * Never render viewports, hero cards, dialogs, or dashboard panels as flat solid hex blocks (e.g. `background: #1c120c`).
   * Every primary visual surface MUST implement the 4-Layer Surface Blueprint: Canvas Base + Micro-Weave/Grain + Structural Bevel Rail + Directional Specular Sheen.

2. **Physical Rail & Border Metaphor:**
   * Generic `border: 1px solid #333` is prohibited.
   * All borders must feature hairline beveling (`border: 1px solid rgba(token, 0.25)`), inset ambient highlights (`inset 0 1px 0 rgba(255,255,255,0.06)`), and physical drop shadows.

3. **Spatial Anti-Gravity (Depth & Elevation):**
   * Elements are decoupled from the base reading surface via multi-stop box shadows (`0 20px 40px -15px rgba(0,0,0,0.7)`).
   * Floating cards must feel like physical plates resting on top of a textured bed.

4. **Palette Token Semantic Binding:**
   * Swatches are material tokens, not colors.
   * Timber tokens (`W-01` to `W-10`) require grain or satin sheen gradients.
   * Textile/Weave tokens require geometric vector meshes.
