## 4. DEPLOYMENT RULES FOR FRONTIEND IMPLEMENTATION
1. **ZERO STILE STATE:** Pure neon colors, floating glass panels, and raw white grids are permanently blacklisted. Everything must feel grounded, framed, and beautifully balanced with texture.
2. **THE ASSEMBLY CAKE:** Stack elements as follows: Outer Wooden Frame (`W-01`/`W-04`) -> Repeating Basketry Rail (`Border Strip 2/3/4`) -> Clean Canvas Content Backdrop (`Background 1/2`) -> Fine Accent Line (`W-10`).
3. **FOLIAGE INTEGRATION:** Vine assets must always trace along a timber core border color. No floating or detached vegetation elements allowed.
