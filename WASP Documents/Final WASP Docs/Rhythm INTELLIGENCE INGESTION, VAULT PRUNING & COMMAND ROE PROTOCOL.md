## 1. PURPOSE & ARCHITECTURE
1. **Zero-Fluff Ingestion:** Raw media (YouTube URLs, papers, whitepapers, transcripts) are stripped down to distilled nuggets only. No clickbait, no padding, no introductory fluff.
2. **Monty as the Final Judge:** Monty on Base 1 evaluates incoming intelligence. If an item lacks functional architecture, code utility, or strategic leverage, it is rejected.
3. **Active Knowledge Pruning:** The knowledge bank is a living source of truth. When new tools, models, or industry standards supersede prior techniques within a category vein, the older methods are replaced or archived. Stale methods will not pollute the agents' context.
4. **Authoritative ROE & Directives Vault:** A dedicated sector for Warlord Inc, Rhythm, SOPs, ROEs, PRDROEs, and live mission directives. When Mike adds a corrective order (e.g., stopping unauthorized color or syntax habits), that directive becomes an immediate hard system constraint across all agents.

---

## 2. PIPELINE STRUCTURE

### Phase A: Tab 12 REVIEW (The Ingestion Hopper)
- **Input:** Single or batch drop for YouTube links, articles, PDFs, and raw code dumps.
- **Fast Extraction:** High-speed LLM (Groq / Gemini Flash) pulls captions/text and produces a structured nugget candidate:
  - `CORE NUGGET`: The technical fact or pattern.
  - `CODE / IMPLEMENTATION`: Exact schema, prompt, or code syntax.
  - `SUPERSEDES`: Explicit note of any prior technique made obsolete.
- **Monty Review Gate:** Monty reviews the candidate via the Base 1 bridge. If approved, Monty signs off for dispatch.
- **Action:** 1-Click `DISPATCH TO OBSIDIAN VAULT`.

### Phase B: Vault Canonical Storage & Pruning
- Incoming data is routed to canonical vein files in Obsidian (e.g., `VEIN_AI_Orchestration.md`, `VEIN_Quant_Trading.md`).
- **Pruning Rule:** If an incoming nugget directly replaces an old approach, the old section is stripped or flagged `[SUPERSEDED - DO NOT USE]`. Agents must read only `[CANONICAL]` state.

### Phase C: Tab 13 DOCS (The Command & Directive Center)
- **Sector 1: Living Knowledge Bank:** Categorized explorer to inspect nuggets, workflows, and current active tech norms.
- **Sector 2: Warlord Inc / Rhythm Command Directives (ROEs & SOPs):**
  - Contains core company directives, Rules of Engagement (ROEs), and Rhythm specifications.
  - Includes a direct editor. When Mike updates an order or writes a rule to eliminate an unwanted pattern, it writes straight to the Markdown file on Base 1.
  - Every agent pulling system instructions parses these files at startup to guarantee total adherence to Mike's directives.
