### Goldie Idea Foundry Overview
* 5-step process for building ideas:
  * Capture: drop idea into the pipeline
  * Classify and root: agent reads and categorizes the idea
  * Plan: agent drafts a proposal
  * Human gate: user approves or rejects the plan
  * Forge: sub-agents build the project

### Technical Components
* Agent OS: dashboard for running the Idea Foundry
* Obsidian vault: stores plans and builds
* Hermes Jarvis: voice-controlled version of the system
* Claude and open-source models: integrated into the Agent OS setup

### Key Benefits
* Reduces idea loss by capturing and automating the building process
* Streamlines planning by providing a finished proposal
* Simplifies decision-making with a single approval or rejection step
* Enables non-technical users to build projects without coding

### Implementation and Support
* AI Profit Boardroom: provides tutorials, coaching calls, and a roadmap for setting up the Idea Foundry
* Community support: over 4,000 members working through the same setup
* Customizable: allows users to wire in their own models and set up the human gate as desired

### Use Cases
* Building apps and tools
* Creating content and managing brand visibility
* Organizing and connecting ideas and projects in a single pipeline
